# Asset Licensing

The source code is licensed under the MIT License. Game art, icons, images, audio, fonts, and other media assets need separate provenance review before public release.

## Current Rule

Do not assume an asset is open source unless its origin and license are documented.

## Required Asset Records

For each non-code asset, record:

- File path
- Author or source
- License
- Link to original source, if applicable
- Whether modification and redistribution are allowed
- Attribution text, if required

## Public Release Requirement

Before a public open-source release:

- Replace unclear or incompatible assets.
- Document generated assets and prompts where appropriate.
- Keep third-party attribution in this file or in a dedicated notices file.
- Prefer assets compatible with reuse, modification, and redistribution.

## Recommended Licenses

Good options for original Island Empires assets:

- CC BY 4.0 when attribution is acceptable
- CC0 when maximum reuse is preferred
- A project-specific asset license only if reuse limits are intentional
