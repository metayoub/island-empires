# Code of Conduct

Island Empires should be a respectful project for players, contributors, maintainers, and server operators.

## Expected Behavior

- Be respectful and specific.
- Assume good intent, but accept correction.
- Keep criticism focused on code, design, balance, documentation, or player impact.
- Help new contributors understand the project.
- Respect privacy and security boundaries.

## Unacceptable Behavior

- Harassment, threats, stalking, or personal attacks
- Hate speech or discriminatory behavior
- Sexualized comments or imagery in project spaces
- Publishing private information without permission
- Encouraging cheating, exploit abuse, or service disruption
- Repeatedly derailing discussions after maintainers ask you to stop

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants who violate this code of conduct.

Report conduct concerns privately to maintainers when possible. If no private contact is configured yet, open a minimal public issue asking for a maintainer contact without sharing sensitive details.
