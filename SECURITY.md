# Security Policy

Island Empires is a multiplayer strategy game, so security and abuse reports are handled seriously.

## Reporting

Report security issues privately before opening a public issue. Include:

- A clear description of the issue
- Reproduction steps
- Affected branch or deployment, if known
- Potential impact
- Suggested fix, if available

If a private security contact is not configured yet, open a minimal public issue asking for a maintainer contact without disclosing exploit details.

## Scope

Security-sensitive areas include:

- Authentication and session handling
- Password reset and email verification
- Authorization checks on player, city, alliance, admin, and support actions
- Payment or donation webhook handling
- Anti-abuse and moderation tools
- Resource, combat, trade, movement, and inventory validation
- Server-side rate limits
- Private messages and reports

## Rules

Do not:

- Access accounts or data you do not own
- Exfiltrate private data
- Disrupt live services
- Publicly disclose active exploits before maintainers can respond
- Use automated testing that degrades service for other players

Good-faith reports are welcome.
