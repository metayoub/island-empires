# Production Rates

Current production config:

| Source | Rate |
| --- | ---: |
| Base wood | 30/hour |
| Base gold | 20/hour |
| Wood worker | 5/hour |
| Gold worker | 3/hour |
| Luxury worker | 4/hour |
| Luxury extractor bonus | +10% per level |
| Forester/luxury booster | +2% per level |

Default Day 1 assignment is 5 wood workers and 5 gold workers:

| Resource | Day 1 production |
| --- | ---: |
| Wood | 55/hour |
| Gold | 35/hour |

First iteration notes:

- Production alone is slow enough to create return pressure.
- Tutorial rewards and PvE should be the accelerators, not replacements for production.
- Warehouse level 1 stores 3000 per resource, enough for the first week if the player spends regularly.
