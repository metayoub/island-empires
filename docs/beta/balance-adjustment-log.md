# Balance Adjustment Log

Balance changes during beta must be small, documented, and monitored.

## Rules

- Track before and after values.
- Avoid large sudden changes unless critical.
- Do not punish players for prior balance.
- Monitor impact after each change.
- Prefer data plus player feedback over single anecdotes.

## Entries

### Template

Date: YYYY-MM-DD

Change: Describe the balance change.

Before: Previous value.

After: New value.

Reason: Why the change is needed.

Expected impact: What should improve.

Metric to monitor: Which beta metric should move.

Rollback condition: What would cause a revert.
